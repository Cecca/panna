# Each entry is a regular expression matched against the qualified names of
# the module members (e.g. `_panna_impl.MinHash.hash`), followed by the
# indented lines that replace the stub of the matching member.

# `hash_sets` is attached to `MinHash` and `MinHash1Bit` in Python, by
# `pypanna/__init__.py`, so stubgen does not see it when it imports the
# extension. The entries below add it to the classes. stubgen has no hook to
# append members to a class, so they replace the stub of `__module__`, a
# member of every class that stubgen otherwise skips: they add `hash_sets`
# without removing anything. Keep them in sync with `_hash_sets`.
